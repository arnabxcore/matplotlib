# Matplotlib Pie Chart 📊
A simple Python project that creates a pie chart using Matplotlib.


## 📌 Project Description
This project demonstrates how to create and customize a pie chart in Python.


The chart represents programming language usage:
- 🐍 Python — 40%
- ☕ Java — 30%
- ⚡ C++ — 30%

## 🛠️ Technologies Used
- Python
- Matplotlib

## 📦 Installation
Install Matplotlib using pip:
```bash
pip install matplotlib
```
## ▶️ Run
```bash
python pie_chart.py
```
